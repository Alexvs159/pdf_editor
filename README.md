# PDF Editor

Простой редактор PDF с графическим интерфейсом (PyQt6 + PyMuPDF). Без OCR.

## Возможности

- Открытие PDF, слева панель миниатюр страниц.
- Если на странице есть текст, он разбивается на блоки; блоки выделяются
  рамками на странице.
- Правка блока — **прямо на странице**: двойной клик по рамке, текст
  редактируется на месте с курсором. Панель параметров шрифта появляется
  сверху.
- Перенос строки — только по явному `Enter` в редакторе; длинный текст
  не переносится сам, блок расширяется по ширине.
- В одном блоке могут быть разные шрифты/размеры/цвета по строкам —
  при правке каждая строка сохраняет свой стиль.
- Работа со шрифтами (см. «Стратегия шрифтов»).

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py            # или путь к PDF файлу в аргументе
```

Тесты модели:

```bash
.venv/bin/python test_document.py
```

## Стратегия шрифтов

При вставке отредактированного текста редактор пытается сохранить исходный
шрифт блока в таком порядке:

1. **Встроенный шрифт** — извлекается из PDF через `doc.extract_font(xref)`
   и подключается на странице через `page.insert_font(fontbuffer=...)`.
   Это сохраняет вид текста лучше всего.
   Ограничение: если шрифт встроен как **субсет** (только начертания
   использованных символов), новые символы, которых нет в субсете, могут
   не отрисоваться. В таком случае — fallback.
2. **Стандартные Base-14** (Helvetica, Times, Courier, Symbol, ZapfDingbats
   и их варианты) — используются напрямую, это всегда безопасно.
3. **Fallback** — подбирается «похожий» Base-14 шрифт по признакам
   (bold/italic/serif/mono) из имени исходного шрифта.

Особый случай: новый текст содержит кириллицу/греческий/CJK — Base-14
шрифты дают `?????`. Такой текст вставляется через `insert_htmlbox`
(Story-движок PyMuPDF): unicode гарантированно пишется, размер и цвет
из блока сохраняются, но гарнитура уже не совпадает с исходной.

Стиль берётся **по строкам**: строка i нового текста наследует шрифт,
размер и цвет строки i исходного блока (новые строки — стиль последней).
Смешение стилей внутри одной строки сводится к первому спану.

Текст вставляется построчно `insert_text` от базовой линии — без переноса
по ширине бокса. Строки переносятся только по явному `\n`. Размер шрифта
не уменьшается: если строка не влезает по высоте, она просто выходит ниже.
Усадка остаётся единственным исключением у нижнего края страницы.

## Управление

- **двойной клик по блоку** — правка текста на месте (курсор в тексте)
- `Enter` в редакторе — явный перенос строки
- `Ctrl+Enter` — применить правку
- `Esc` — отменить правку и закрыть редактор
- `Ctrl+Z` — отменить последнюю правку
- `Ctrl+S` — сохранить как…
- `Ctrl+O` — открыть PDF

Блок можно **перемещать мышью** (потянуть за рамку). На верхней панели
появляются выбор шрифта, размер (чекбокс «Авто» — размер по строкам)
и кнопки «Применить»/«Отмена»; «Применить» фиксирует текст, шрифт, размер
и позицию. Повторные правки того же текста не меняют ни размер,
ни позицию блока.

Список шрифтов: «Авто (сохранить исходный)» оставляет построчные стили
блока (встроенный шрифт, если он есть в PDF); либо можно выбрать любой
встроенный шрифт документа или стандартный Base-14/CJK — тогда шрифт
меняется во всём блоке.

- `document.py` — модель: рендер, миниатюры, текстовые блоки, правка, сохранение. Без GUI.
- `window.py` — главное окно PyQt6, in-place редактор, верхняя панель шрифта.
- `main.py` — точка входа.
- `test_document.py` — self-check модели (без GUI).
- `test_gui_edit.py` — GUI-смоки in-place правки (offscreen).
